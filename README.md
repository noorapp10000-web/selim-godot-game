# سليم: ساعة أبويا (Selim: Father's Watch)

مشروع لعبة **سليم: ساعة أبويا** على محرك **Godot 4.3** بالصوت والتمثيل المصري الكامل (الإصدار v10).

## المميزات والتعديلات المطبقة:
1. **اسم اللعبة:** «سليم: ساعة أبويا» مع ضبط أبعاد وتنسيق الشعار والأزرار في الشاشة الرئيسية.
2. **شاشة اختيار الصعوبة عند البدء:** إمكانية إدخال اسم للمغامرة واختيار مستوى الصعوبة (عادي، متمرس، أسطوري) قبل الدخول للعب.
3. **نظام المغامرات المتعددة:** دعم فتح وإدارة عدة مغامرات مستقلة باسم مختلف وصعوبة وتقدم مستقل لكل مغامرة.
4. **تنبيه الإعدادات:** تنبيه واضح عند محاولة تغيير مستوى الصعوبة من الإعدادات بأنه سيُعيد الفصل من البداية.
5. **إصلاح شيك بوينت الزعيم:** حماية نقطة الحفظ قبل الزعيم بحيث لا تُفعل إلا بعد القضاء على جميع الأعداء في المنطقة، وحفظ حالتهم لمنع ظهورهم من وراء السور بعد الموت أو إعادة التشغيل.
6. **أزرار التحكم باللمس:** تكبير أزرار الحركة (يمين/شمال) بنسبة 25% مع إضافة تباعد مريح بينهما.
7. **صوت الراوي:** إعادة توليد صوت النهاية لنطق الاسم الجديد «سليم: ساعة أبويا» بنفس النبرة وجودة الأداء المصري.
